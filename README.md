## ♡ about

a cozy little python program that converts ukrainian hryvnias (uah) into us dollars (usd).

just enter your money and the exchange rate, and let the kitty do the math. 🎀

## 💸 how it works

| input | description |
|---|---|
| s | amount in uah |
| k | exchange rate (uah per usd) |
| ♡ | amount in usd |

**formula:** `usd = s / k`
